# Lattice

Lattice is a Solidity library of [EIP-2535](https://eips.ethereum.org/EIPS/eip-2535) Diamond modules. Most
modules ship as a stateless facet plus a library that keeps its state in one
[ERC-7201](https://eips.ethereum.org/EIPS/eip-7201) namespace, so many modules can be cut into one Diamond
proxy without storage collisions. The contracts are unaudited; evaluate them with local or testnet assets.

## Quickstart

Install [Foundry](https://getfoundry.sh), then build and test from a clean checkout:

```sh
git clone --recurse-submodules https://github.com/dadadave80/lattice.git
cd lattice
forge build
forge test --match-contract 'GovernedVault(Upgrade)?Test' -vv
```

To use Lattice as a dependency, install a release tag with `forge install dadadave80/lattice@vX.Y.Z`; the
[README install steps](../../README.md#install--usage) cover remappings and pinning.

## Build this site

```sh
make doc        # forge doc + Vocs build into docs/site/dist/public, then a link check
make doc-serve  # the same pages on a local Vocs dev server
```

Both need Node.js 22.15 or later; the Vocs toolchain is pinned in `docs/site/package-lock.json`.
